# Font glyph

Glyph PBF của Noto Sans (Regular, Medium) cho MapLibre, lấy từ [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets). Noto Sans phát hành theo giấy phép [SIL Open Font License 1.1](https://openfontlicense.org/).

Mỗi file `<bắt đầu>-<kết thúc>.pbf` chứa 256 ký tự Unicode. Tiếng Việt dùng `0-255`, `256-511` và `7680-7935`.
